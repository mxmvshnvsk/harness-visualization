# Эталонные трейсы

Записанные сессии по урокам проекта (этап 9.3): у склонировавшего проект есть что смотреть, и от них можно ветвиться. Интерфейс показывает их в «Сессиях и трейсах» с меткой «пример»; одноимённый трейс из `traces/` главнее. Перед тем как положить трейс сюда, проверено: заголовок `Authorization: Bearer ***`, ни одного ключа (`sk-…`, `AQVN…`, `tvly-…`), ни одного пути домашней папки.

Модель — DeepSeek, база знаний — вымышленная компания «Кедр Софт» (`packages/mcp-server/data/`). Уроки — в `docs/plan.md`.
