# Сводка встречи

Протоколы встреч лежат в базе знаний в разделе `meetings/`.

## Порядок

1. Найди протокол встречи: по названию, дате или проекту.
2. Выпиши решения — только то, о чём договорились, а не что обсуждали.
3. Для каждого решения — ответственный и срок, если они есть в протоколе. Нет — пометь «не
   назначен» или «без срока», не придумывай.
4. Отдельно — открытые вопросы: что осталось без решения.

## Формат

**Встреча:** название, дата, ведущий — путь к протоколу.

**Решения:**

| Решение | Ответственный | Срок |
| ------- | ------------- | ---- |

**Открытые вопросы:** списком.
