# Скиллы

Скилл — папка с `SKILL.md` и, если нужно, дополнительными файлами. Формат — как у Agent Skills
Anthropic ([обзор](https://platform.claude.com/docs/en/agents-and-tools/agent-skills/overview)):
в начале `SKILL.md` — YAML с `name` и `description`, дальше инструкция.

- `name` — до 64 символов: строчные латинские буквы, цифры и дефис; совпадает с именем папки.
- `description` — до 1024 символов: что делает скилл и когда его брать. По нему модель решает,
  загружать ли скилл, поэтому описание важнее всего остального.

Загрузка поэтапная. В system prompt — только каталог: имя и описание каждого скилла. Модель
выбирает скилл и загружает его инструкцию тулом `load_skill`, а дополнительные файлы читает
`read_skill_file` — только когда инструкция на них ссылается.

Режимы — в `harness.config.json`, раздел `skills`: по умолчанию `on_demand` (каталог и
`load_skill`); `always` — инструкция целиком в system prompt с самого начала; `manual` — в
каталоге скилла нет, его загружает пользователь командой `/имя` в начале вопроса.

Примеры написаны под базу знаний «Кедр Софт» (`packages/mcp-server/data/`):

| Скилл             | Режим     | Что делает                                                                    |
| ----------------- | --------- | ----------------------------------------------------------------------------- |
| `policy-answer`   | on_demand | ответ по регламенту: действующая редакция, дословная цитата, расхождения      |
| `incident-review` | on_demand | разбор инцидента по шаблону компании                                          |
| `meeting-summary` | manual    | сводка встречи: решения, ответственные, сроки — по команде `/meeting-summary` |
