# Разбор авансового отчёта

Портал «Улей» выгружает авансовый отчёт в CSV. Нужна функция `parseExpenses(csv)`
в `src/expenses.js`, которая возвращает

```js
{
  rows: ([{ date, description, amountKopecks }], totalKopecks);
}
```

Формат выгрузки:

- разделитель — точка с запятой `;`, первая строка — заголовок `дата;описание;сумма`;
- дата — «ГГГГ-ММ-ДД»;
- сумма — рубли, копейки через запятую: `1200,50`; копеек может не быть: `850`;
  разряды могут разделяться пробелом, в том числе неразрывным: `12 345,00`;
- описание может быть в двойных кавычках, тогда внутри может встретиться `;`;
- строки разделяются `\n` или `\r\n`, пустые строки пропускаются.

Суммы — целые копейки, без дробных рублей: `1200,50` → `120050`. Тесты — `node --test`.
