# Код-арена

Задачи для этапа 10: агент правит код в копии проекта, сам запускает видимые тесты, а харнесс
принимает работу скрытыми тестами.

- `kedr-hr/` — проект «кадровые расчёты»: правила регламентов «Кедр Софт» кодом.
  Тексты регламентов харнесс кладёт в копию проекта, в `docs/regulations/`, из базы знаний
  (`packages/mcp-server/data/regulations/`).
- `tasks/<id>/` — задача:
  - `task.json` — название, вид, чему учит; `editableTests` — тесты, которые агенту можно менять;
  - `TASK.md` — текст задачи, его агент видит в корне копии;
  - `files/` — что задача меняет или добавляет в проекте;
  - `acceptance/` — скрытые тесты: в копию агента не попадают;
  - `solution/` — эталонное решение. `pnpm arena --verify` проверяет, что без решения приёмка
    не проходит, а с ним — проходит.

Приёмка: видимые тесты зелёные, скрытые зелёные, видимые тесты не изменены
(кроме `editableTests`).
