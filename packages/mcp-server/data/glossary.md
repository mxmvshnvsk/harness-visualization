# Глоссарий

- **«Улей»** — внутренний портал сотрудников: заявки, отпуска, доступы, обучение.
- **«Ракета»** — новое мобильное приложение для доставки.
- **«Сокол»** — API для партнёров.
- **«Маяк»** — система мониторинга и оповещений.
- **«Компас»** — поиск по базе знаний компании.
- **Дежурный** — инженер, который в течение недели первым реагирует на инциденты.
- **Разбор** — документ после инцидента: что случилось, почему и что сделаем. Виноватых не ищут.
- **Гибрид** — формат работы: часть дней дома, часть в офисе.
- **Авансовый отчёт** — заявка на компенсацию рабочих расходов с чеками.
