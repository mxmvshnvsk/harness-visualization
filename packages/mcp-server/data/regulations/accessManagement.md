# Порядок выдачи доступов

## Как получить доступ

1. Заявка на доступ создаётся на портале «Улей», раздел «Доступы». В заявке укажите систему, нужный уровень прав и срок.
2. Заявку согласует руководитель сотрудника, затем владелец системы. Доступы к продакшен-окружению дополнительно согласует отдел безопасности.
3. Обычный срок выдачи — один рабочий день, к продакшену — до трёх рабочих дней.

## Принцип минимальных прав

4. Доступ выдаётся только к тому, что нужно для работы. Права администратора — на ограниченный срок, по умолчанию на 7 дней.
5. Раз в квартал владельцы систем пересматривают список доступов и отзывают лишние.

## VPN

6. VPN нужен для доступа к внутренним системам из дома. Клиент и инструкция — в разделе «Доступы» портала «Улей».

## Увольнение и перевод

7. При увольнении все доступы отзываются в последний рабочий день до 18:00.
8. При переводе в другой отдел доступы прежнего отдела отзываются через 14 дней.
