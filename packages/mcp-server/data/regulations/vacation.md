# Регламент об отпусках

## 1. Общие положения

1.1. Регламент действует для всех сотрудников «Кедр Софт», работающих по трудовому договору.

1.2. Вопросы по регламенту — в отдел кадров, к Марии Орловой.

## 2. Ежегодный отпуск

2.1. Ежегодный оплачиваемый отпуск составляет 28 календарных дней. Право на отпуск за первый год работы возникает по истечении шести месяцев непрерывной работы.

2.2. По соглашению с руководителем отпуск может быть предоставлен раньше.

2.3. Отпуск может делиться на части, при этом хотя бы одна из частей должна быть не менее 14 календарных дней.

2.4. Заявление подаётся на внутреннем портале «Улей» не позднее чем за две недели до начала отпуска. Руководитель согласует его в течение трёх рабочих дней.

## 3. Перенос и отзыв

3.1. Перенос отпуска согласуется с руководителем и отделом кадров.

3.2. Неиспользованные дни отпуска переносятся на следующий год автоматически, но не более 14 дней.

3.3. Отзыв из отпуска возможен только с согласия сотрудника. Неиспользованные из-за отзыва дни предоставляются в удобное для сотрудника время.

## 4. Отпуск без сохранения заработной платы

4.1. Оформляется отдельным заявлением на портале «Улей». Продолжительность — по согласованию с руководителем, но не более 30 календарных дней в году.
