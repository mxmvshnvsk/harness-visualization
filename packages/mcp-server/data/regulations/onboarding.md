# Адаптация новых сотрудников

## Первый день

1. Офис-менеджер Татьяна Соловьёва выдаёт пропуск и ноутбук.
2. Отдел инфраструктуры заводит учётную запись, почту и доступ к порталу «Улей».
3. Руководитель знакомит с командой и назначает наставника.

## Первая неделя

4. Вводный курс по информационной безопасности — обязателен, проходится на портале «Улей».
5. Встреча с наставником каждый день по 30 минут.

## Испытательный срок

6. Испытательный срок — три месяца. Через месяц и через три месяца — встречи с руководителем по итогам.
7. План на испытательный срок составляет руководитель в первую неделю и согласует с сотрудником.

Ответы на частые вопросы новичков — в `faq/newcomersFaq.md`.
