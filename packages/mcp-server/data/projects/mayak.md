# Проект «Маяк»

**Цель:** единая система мониторинга и оповещений вместо трёх разрозненных инструментов.

**Команда:** отдел инфраструктуры, руководитель — Роман Егоров.

**Статус:** работает в продакшене для 70% сервисов. Оставшиеся сервисы переводятся до конца 2026 года.

## Что уже сделано

- Единые дашборды для всех команд.
- Оповещения дежурному в мессенджер и звонком для инцидентов уровня 1.
- Разбор инцидента 21 августа показал, что оповещение пришло через 12 минут — после этого порог срабатывания уменьшен до 2 минут.

## Планы

- Автоматическое создание карточки инцидента при оповещении уровня 1.
- Подключение мобильного клиента «Ракета» до релиза.
