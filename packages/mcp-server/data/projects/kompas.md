# Проект «Компас»

**Цель:** внутренний поиск по базе знаний компании — регламентам, протоколам встреч, описаниям проектов. Сотрудник задаёт вопрос своими словами и получает ответ со ссылками на документы.

**Команда:** отдел аналитики. Руководитель — Игорь Лебедев, разработка — Николай Фёдоров.

**Статус:** прототип показан на демо 1 октября 2026 (см. протокол). Поиск работает по смыслу, а не только по словам.

**Срок первой версии:** конец первого квартала 2027 года.

## Как устроен

- Документы режутся на фрагменты, для каждого считается эмбеддинг.
- Вопрос сотрудника тоже превращается в эмбеддинг, ищутся ближайшие фрагменты, ответ формирует языковая модель по найденному.

## Риски

1. Качество поиска на документах со сложной структурой — таблицах и длинных протоколах.
2. Устаревшие документы: поиск может найти старую редакцию регламента. Нужна пометка актуальности.
3. Доступы: сотрудник не должен находить документы, к которым у него нет доступа.
