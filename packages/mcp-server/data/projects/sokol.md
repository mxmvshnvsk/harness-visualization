# Проект «Сокол»

**Цель:** открытый API для партнёров — ресторанов и магазинов, чтобы они передавали заказы в доставку напрямую из своих систем.

**Команда:** отдел платформы, технический руководитель — Артём Григорьев.

**Статус:** закрытая бета с пятью партнёрами с июля 2026. Публичный запуск — после релиза «Ракеты», ориентировочно в феврале 2027.

## Решения

- Авторизация партнёров по ключам API с ограничением частоты запросов.
- Документация API публикуется на отдельном портале для разработчиков.

## Риски

- Артём Григорьев одновременно занят в «Ракете»: в ноябре возможна просадка по срокам «Сокола».
