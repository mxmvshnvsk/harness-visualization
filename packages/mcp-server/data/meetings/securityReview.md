# Проверка безопасности платёжного модуля — 7 октября 2026

**Участники:** Сергей Никитин, Артём Григорьев, Дмитрий Волков, Евгений Морозов.

## Результаты

1. Данные карт приложение не хранит — подтверждено.
2. Найдено: в журналах отладки Android-версии записывается номер телефона клиента целиком. Нужно маскировать.
3. Найдено: тестовый ключ платёжного шлюза лежал в репозитории в файле настроек. Ключ отозван, перенесён в менеджер секретов.

## Решения

- Евгений Морозов маскирует телефон в журналах до 14 октября.
- Повторная проверка — перед публичным релизом, в начале декабря.
- Тема утечки ключей — в обязательный курс безопасности для разработчиков.
