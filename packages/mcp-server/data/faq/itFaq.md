# Частые вопросы к отделу инфраструктуры

**Ноутбук сломался — что делать?**
Напишите в канал #it-help. Замену выдают в течение одного рабочего дня, удалённым сотрудникам — отправляют курьером.

**Забыл пароль.**
Сброс — через портал «Улей», кнопка «Не помню пароль». Нужен телефон, привязанный к учётной записи.

**Не работает VPN.**
Проверьте, что клиент VPN обновлён до последней версии. Если не помогло — #it-help, приложите скриншот ошибки.

**Как получить доступ к системе?**
Заявка в разделе «Доступы» портала «Улей». Обычно выдают за один рабочий день.

**Можно ли поставить свою программу на рабочий ноутбук?**
Да, из корпоративного каталога программ. Программы не из каталога согласует отдел безопасности.
