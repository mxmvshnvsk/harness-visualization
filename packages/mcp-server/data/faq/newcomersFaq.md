# Вопросы новичков

**Кто мой наставник?**
Его назначает руководитель в первый день. Если не назначил — спросите руководителя или Марию Орлову.

**Что обязательно сделать в первую неделю?**
Пройти курс по информационной безопасности на портале «Улей» и настроить двухфакторную аутентификацию.

**Где найти регламенты?**
В базе знаний, раздел регламентов. Скоро вопросы можно будет задавать поиску «Компас».

**Сколько длится испытательный срок?**
Три месяца.

**Можно ли работать из дома с первого дня?**
Можно по гибридному графику, но первую неделю лучше провести в офисе — так проще познакомиться с командой.
