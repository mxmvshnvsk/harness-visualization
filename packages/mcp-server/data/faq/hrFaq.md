# Частые вопросы к отделу кадров

**Сколько дней отпуска положено?**
28 календарных дней в год. Право на отпуск появляется через шесть месяцев работы.

**Сколько дней в неделю можно работать из дома?**
До двух дней в неделю, по согласованию с руководителем.

**Как оформить отпуск?**
Заявление на портале «Улей», не позднее чем за две недели.

**Что делать, если заболел?**
Сообщить руководителю в первый день и прислать номер электронного больничного в отдел кадров.

**Когда пересматривают зарплаты?**
Раз в год, в январе.
