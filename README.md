# Harness Visualization

Учебный харнесс для ИИ-агентов с визуализацией потока данных. Видно, как запрос пользователя превращается в контекст, что именно уходит в модель, какие тулы она просит вызвать и как работают MCP, RAG, память, скиллы и управление контекстом.

Работаем с настоящей моделью, без заглушек: смысл проекта в том, чтобы увидеть, что происходит на самом деле.

> **Статус:** этап 0 — каркас проекта. Этапы и принятые решения — в [docs/plan.md](docs/plan.md).

## Требования

- Node.js 26 (LTS), версия указана в `.nvmrc`.
- pnpm. В Node 25+ corepack больше не входит в поставку, поэтому, например: `npm install --global corepack@latest && corepack enable`.
- Ключ DeepSeek API — понадобится с этапа 1. Подойдёт и любой другой OpenAI-совместимый API.

## Быстрый старт

```bash
pnpm install
cp .env.example .env   # заполнить ключи, понадобятся с этапа 1
pnpm check
```

## Команды

| Команда          | Что делает                                    |
| ---------------- | --------------------------------------------- |
| `pnpm build`     | Собирает все пакеты                           |
| `pnpm typecheck` | Проверяет типы TypeScript                     |
| `pnpm lint`      | Проверяет код ESLint                          |
| `pnpm lint:fix`  | Исправляет то, что ESLint умеет исправить сам |
| `pnpm format`    | Форматирует код Prettier                      |
| `pnpm check`     | Типы, линтер и форматирование — всё вместе    |
