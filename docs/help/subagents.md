# Субагенты

**Субагент** — второй цикл агента со своей историей. Главный агент поручает ему задачу тулом `delegate_task`, субагент работает сам — свой system prompt, свои тулы, свои шаги — и возвращает короткий отчёт. Этот отчёт и есть результат тула: больше главный агент о работе субагента ничего не узнаёт.

Модель та же, политика разрешений та же. Отличается только история: она своя, короткая и про одну подзадачу.

## Зачем

- **Контекст главного не растёт** от сырых результатов тулов: в нём поручение и отчёт. Во втором прогоне примера два исследователя прочитали ≈4,8 тыс. токенов, а главному вернулось ≈2,4 тыс.
- **Независимые поручения идут одновременно.** Несколько `delegate_task` в одном шаге харнесс запускает разом (`subagents.parallel`); остальные тулы — по очереди.
- **Тулы можно сузить.** У `researcher` — только чтение: поиск и документы базы знаний, файлы песочницы.

## Чем платим

- Каждый субагент заново получает system prompt и описания своих тулов — это токены в каждом его запросе.
- Отчёт — пересказ: чего субагент не написал, главный не узнает.
- Субагенты не видят друг друга: связать их выводы может только главный.
- Многоагентные схемы заметно дороже обычного разговора: по наблюдениям Anthropic, агент тратит примерно в 4 раза больше токенов, чем чат, а система из нескольких агентов — примерно в 15 раз.

## Лимит шагов

У субагента свой лимит (`subagents.agents.<имя>.maxIterations`). На последнем шаге харнесс не обрывает работу, а просит ответить по найденному: тулы остаются описаны, но звать их нельзя (`tool_choice: none`). В первом прогоне примера — до этой правки — оба исследователя упёрлись в лимит без отчёта, и главный перечитал всё сам.

## Где смотреть

- **Агенты** — дорожки по настоящему времени (одновременную работу видно как есть), поручения и отчёты, самый большой prompt у каждого.
- **Инспектор** — шаги субагента раскрываются под строкой поручения.
- **Сырые события** — у событий субагента поле `agentId`; фильтр «главный / researcher-1…».

Включаются галочкой «Субагенты» в форме новой сессии или флагом `--subagents`; по умолчанию выключены.
