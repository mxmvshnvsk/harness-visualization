# Справка интерфейса

Тексты для кнопок «Что это?» и подсказок на терминах. Интерфейс берёт их отсюда при сборке (`packages/ui/src/help/helpTopics.ts`); имя файла — идентификатор темы.

Формат — небольшое подмножество Markdown, которое понимает интерфейс: заголовок `#` (название темы), подзаголовки `##`, абзацы, списки `-`, **жирный**, `код` и ссылки `[текст](https://…)`. В конце — строка «Проверено: дата» и раздел «Источники»: факты о внешних сервисах меняются, и читатель должен видеть, когда их сверяли и где.

Термины индустрии — по-английски (`docs/code-style.md`, «Термины в терминале и интерфейсе»).
