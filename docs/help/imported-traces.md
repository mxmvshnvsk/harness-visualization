# Трейсы других харнессов

Плеер, инспектор и «Диалог» умеют показывать не только наши прогоны. **Адаптер** переводит запись чужого харнесса в наши события — и сессию Claude Code можно разобрать по шагам так же, как сессию нашего агента с DeepSeek.

## Как открыть

- В интерфейсе — «Сессии и трейсы» → «Открыть трейс другого харнесса…». Трейс сохранится в `traces/` с чипом «Claude Code».
- В терминале — `pnpm import-trace claude-code <файл>.jsonl`.

Записи Claude Code лежат в `~/.claude/projects/<папка проекта>/<id сессии>.jsonl`. Папка скрытая: в окне выбора файла на Mac — Cmd+Shift+.

## Что переводится

- Вопросы пользователя.
- Ответы модели: рассуждение, текст, вызовы тулов. Claude Code пишет один ответ несколькими записями — по записи на блок; адаптер собирает их по `message.id`.
- Результаты тулов, ошибки тулов.
- Токены и кэш. У Anthropic вход делится на три счётчика: без кэша, прочитано из кэша, записано в кэш. У нас «попадание» — прочитанное, «промах» — остальное.
- Компакция истории: размер до и после и сама сводка.

## Чего в записи нет

Интерфейс показывает это в шапке, а не пустотой:

- **Тело запроса.** System prompt, история и описания тулов в запись не попадают — только ответы. Поэтому тело запроса в инспекторе пустое и ветвиться нельзя.
- **Разрешения и сеть.** Claude Code не пишет решения политики и маршруты запросов.
- **Цена.** Тарифы Anthropic в адаптере не заданы.
- **Субагенты.** Их записи (`isSidechain`) пока пропускаются.

## Осторожно

- Формат не документирован: это внутренняя запись Claude Code, она меняется от версии к версии. Адаптер берёт только устойчивое ядро — сообщения в формате Anthropic Messages API. Описания формата — только от сообщества.
- В результаты тулов попадает всё, что прочитала модель, — в том числе `.env`. Адаптер маскирует ключи (`sk-…`, `tvly-…`, `ghp_…`, `Bearer …`, `API_KEY=…`) и домашнюю папку, но перед тем как делиться трейсом, просмотрите его.
