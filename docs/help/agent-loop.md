# Харнесс и цикл агента

Модель сама ничего не выполняет: она получает сообщения и описания tools и возвращает либо текст, либо просьбу вызвать tool (`tool_calls`). Всё остальное делает **харнесс** — код вокруг модели.

## Один шаг агента

- Харнесс собирает prompt: system prompt, вопрос пользователя, всё, что было раньше, и описания tools.
- Отправляет его модели — это `model_request` с `purpose: agentStep`.
- Модель отвечает. Если в ответе `tool_calls`, харнесс проверяет каждый вызов политикой разрешений, выполняет разрешённые и добавляет результаты в prompt сообщениями `role: tool`.
- Следующий шаг отправляет модели всё заново — вместе с результатами. Цикл кончается, когда модель отвечает текстом.

Каждый шаг заново отправляет весь контекст — поэтому input tokens растут от шага к шагу, а начало prompt часто уже лежит в кэше (см. «prompt cache»).

## Служебные запросы

Кроме шагов агента харнесс иногда сам спрашивает модель: переформулировать вопрос в поисковый query (`queryRewrite`) или оценить claim ответа (`groundingJudge`). Это тоже запросы к модели со своей стоимостью, но не шаги агента.
