# Retrieval

Чтобы ответить по документам, нужно их найти. Кто ищет и кто формулирует запрос — настройка `retrieval.mode`:

- `tool` — ищет **модель**: у неё есть tools поиска (`kedr__search`, `kedr__semantic_search`), она сама решает, искать ли и какими словами;
- `auto` — ищет **харнесс** до первого запроса, по вопросу пользователя как есть, и подмешивает найденное в контекст (`context_retrieved`);
- `rewrite` — тоже харнесс, но сначала просит модель переформулировать вопрос в поисковый query (`queryRewrite`, `query_rewritten`).

## Что из этого видно на записанных сессиях

- Подмешанное не нейтрально: модель часто ищет дальше от него узко и пропускает то, что нашла бы сама.
- Переформулировка делает запрос «официальным» и может потерять неформальный документ вроде FAQ.
- Один прогон ничего не доказывает: сравнивать режимы нужно повторами (`pnpm compare-runs`).
