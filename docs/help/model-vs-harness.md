# Где кончается модель и начинается харнесс

**Модель за API — не харнесс.** DeepSeek API получает историю разговора и описания тулов, возвращает текст или просьбу вызвать тул. Сама она ничего не выполняет и между запросами ничего не помнит: всю историю харнесс присылает каждый раз заново.

## Тулы — меню в каждом запросе

Харнесс кладёт описания тулов в каждый запрос к модели — поле `tools` в теле `model_request`: имя, назначение, JSON Schema аргументов. Модель выбирает из меню и придумывает только аргументы — что искать, какой файл открыть, какой адрес. Тул не из меню харнесс не выполнит и вернёт модели ошибку «нет такого тула».

Выполняет харнесс: проверяет вызов политикой разрешений (`permission_evaluated`), запускает тул на вашей машине и кладёт результат в историю следующего запроса.

## На одном трейсе

Пример `19b7e04d` — «найди информацию об отпусках моих коллег»:

- **Меню.** В первом `model_request` — 11 тулов: файлы песочницы, `web_search`, `fetch_url` и четыре тула MCP-сервера базы знаний `kedr__…`.
- **Просьба.** Модель вернула не ответ, а два `tool_calls` сразу: `kedr__search` с `{"query": "отпуск", "limit": 20}` и `list_files` с `{"path": "."}`. Слово «отпуск» и лимит 20 — её выбор.
- **Политика.** Оба вызова — класс действия `read`, решение `allow`.
- **Выполнение.** `list_files` харнесс выполнил сам, а `kedr__search` отправил MCP-серверу базы знаний (`mcp_message`, `tools/call`) — это отдельный процесс на вашей машине, модель о нём не знает.
- **Результат.** Во втором `model_request` два новых сообщения `role: tool` — результаты обоих вызовов. Модель видит их впервые и решает, что дальше. Всего за сессию — 4 запроса и 7 вызовов тулов.

## Продукт — это модель плюс харнесс

Чат chat.deepseek.com — уже продукт со своим харнессом: поиск, файлы, история разговоров. У части провайдеров в API есть **server tools** — например, веб-поиск у Anthropic и OpenAI: их выполняет провайдер на своей стороне, а ваш харнесс видит только результат. У DeepSeek API таких тулов нет: всё, что выполняется, выполняет наш харнесс, и всё это видно в трейсе.

## Источники

- [DeepSeek API — Tool Calls](https://api-docs.deepseek.com/guides/tool_calls/) — модель возвращает `tool_calls`, выполняет их приложение.
