# Tool calls

Модель не умеет читать файлы или ходить в интернет. Она умеет **попросить** об этом.

- Харнесс описывает модели tools: имя, назначение и JSON Schema аргументов.
- Вместо ответа модель возвращает `tool_calls`: какой tool вызвать и с какими аргументами.
- Харнесс проверяет вызов политикой разрешений, выполняет его и возвращает результат сообщением `role: tool` с тем же `tool_call_id`.
- На следующем шаге модель видит результат и решает, что дальше.

## Что видит модель, а что — только харнесс

У результата две части: `content` — ровно то, что получит модель, и `details` — подробности для трейса и токеномики (сервер MCP, стоимость поиска, сколько байт скачано). Модель `details` не видит.

Тулы MCP-серверов харнесс называет «сервер__тул» (`kedr__search`): так модель различает тулы разных серверов, а харнесс знает, куда отправить вызов.
